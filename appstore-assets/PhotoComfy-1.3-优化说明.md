# PhotoComfy 1.3 优化说明

## 版本信息

- 应用名称：PhotoComfy
- 当前版本：1.3（`CFBundleShortVersionString`；仓库根 `Cargo.toml` 按 Cargo 要求写作 `1.3.0`）
- App Store Connect 构建号：10
- 发布方式：只上传 App Store Connect 供 TestFlight 内测；本版本未创建 Git tag 和 GitHub Release，未提交审核
- Bundle ID：`photoComfy`
- 支持设备：iPhone、iPad
- 对照版本：1.2

## 1. iPad：绘画、填充和选择只响应 Apple Pencil

- 修复手指可以在 iPad 上落笔画线的问题。画笔、铅笔、混合器画笔、颜色替换、橡皮擦、背景橡皮擦、
  图章、修复画笔、历史记录画笔、模糊/锐化/涂抹/减淡/加深/海绵等画笔类工具只响应 Apple Pencil；
  手指按下时不起笔，状态栏提示「绘画、填充和选区需要使用 Apple Pencil」。
- 选框、套索、多边形套索、磁性套索、魔棒、快速选择、对象选择、钢笔与路径工具、形状、直线、渐变和油漆桶
  同样只响应 Apple Pencil；用手指松手时不会提交选区或填充。
- 液化、内容识别填充、选择并遮住、消失点等工作区里的画笔手势遵循同一规则。
- 修复三处 Apple Pencil 缺陷：手指按在画布上时 Apple Pencil 落笔不出线条；手掌或手指触碰画布会打断正在绘制的笔画；
  Apple Pencil 落笔时误弹出长按菜单。系统取消触摸（例如手掌触发的系统手势）后，指针不再停留在按下状态。
- 手指仍用于界面操作：按钮、菜单、滚动、双指平移和缩放画布，以及移动工具等不涉及绘制的工具。

## 2. iPhone：不提供绘画、填充和选择

- 工具栏不显示第 1 节列出的绘画与选择工具。
- “选择”菜单置灰，“编辑 › 填充 / 描边 / 内容识别填充”“图层 › 新建填充图层”“滤镜 › 液化”置灰。
- 浏览、图层、调整、滤镜、裁剪与变换、文字等其余功能不变。

## 3. Android 不做上述处理

- Android 的绘制输入策略保持原样，手指和触控笔都可以绘画；本版本没有构建或发布 Android 产物。

## 4. iOS 与 Android 的绘制控制相互独立

- 绘制输入策略由各平台外壳单独决定，共享界面代码只执行策略，不内置 iOS 规则。
- iPad 与 iPhone 的判定只取自系统的设备类型（`userInterfaceIdiom`），不按屏幕尺寸推断。

## 已完成的验证

- `photocraft-ui-egui` 定向测试 323 项通过（绘制策略、手指输入、菜单、工具栏、手写笔、双指手势、i18n）；
  `photocraft-ios` 单元测试 25 项通过；Clippy 无警告。
- iOS 27.0 模拟器（iPad Pro 11 英寸、iPhone 17）：开发构建上的绘制探针回放 9 种手势，共 18 行结果全部符合预期。
- 无 AIGC 配置下的启动与合规检查、归档与 App Store Connect 上传结果见本次交付记录。

未验证：真实设备上手指与 Apple Pencil 的实际触控行为（本机没有可用的真机自动化）；Android 构建。

## 面向用户的简短更新说明

iPad 上的绘画、擦除和选择现在只响应 Apple Pencil，手指不再误触落笔，手掌搭在屏幕上也不会打断笔画；
iPhone 不再显示绘画与选择工具，专注于浏览、调整、滤镜与文字。
